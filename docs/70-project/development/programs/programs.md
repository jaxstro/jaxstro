# Programs

A program connects a demonstrated consumer need to a proposed Jaxstro change.
It names the package that owns each scientific assumption, the smallest first
case, the evidence needed for a decision, and the claim that evidence permits.
A program page is a plan, not an implemented API or a science qualification.

| Program | Status | First consumer path |
| --- | --- | --- |
| [Unit-aware scientific computing](./unit-aware-scientific-computing.md) | Phased design; boundary pilot first, post-v1 ecosystem adoption targeted | Progenax to Informax kinematics, then photometry, dynamics, and learned-surrogate lanes |

The [](../future-capabilities-roadmap.md) lists possible Jaxstro capabilities.
Programs test a specific adoption path before that roadmap becomes a package-wide
change.
