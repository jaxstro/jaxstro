# JaxtroViz design records

Each figure receives a short design record before it is treated as website
evidence. A record names:

1. the learner question;
2. the public code or data supplying the visual claim;
3. the visual encoding and accessibility contract;
4. what the figure does **not** prove; and
5. the executable acceptance gate.

These records are review artifacts. The registry and tests remain the executable
owners of paths, seeds, builders, and freshness.
